# Chem Arena ⚗️

เกมออนไลน์ฝึกอ่านชื่อสารอินทรีย์ (แอลเคน / แอลคีน / แอลไคน์) สไตล์ Roblox
ตั้งชื่อ → แต่งตัว → เข้าห้องรอ → กดเข้าร่วมรอบ → แข่ง 10 มินิเกมเอาชีวิตรอด (พลาดครั้งเดียวตกรอบ) คนสุดท้ายที่รอดชนะ

```
client/   หน้าเกม 3D (PlayCanvas + Vite)   -> host บน GitHub Pages
server/   เซิร์ฟเวอร์ห้องรวม/ตรวจคำตอบ (Node.js + ws) -> host บน Render / Railway ฯลฯ
```

## วิธีเล่น
- **คอม:** WASD เดิน, Space กระโดด, **ลากเมาส์ = หมุนกล้องรอบตัวได้ทุกด้าน (ซ้าย-ขวา + เงยก้ม)**, ล้อเมาส์ = ซูม, Q/E หมุนกล้อง, Enter แชท, 1–7 ท่าเต้น, **กดค้าง M = พูด**, C สลับกล้อง (มองทั้งสนาม ↔ ตามตัวละคร) ระหว่างรอบ
- **มือถือ/แท็บเล็ต:** ลากนิ้วที่ซ้ายล่างเพื่อเดิน (จอยสติ๊กจะโผล่ตรงที่แตะ), ปุ่ม ⬆ กระโดด, ลากนิ้วบริเวณอื่นเพื่อหมุนกล้อง (ซ้าย-ขวา + เงยก้ม), ถ่างสองนิ้วเพื่อซูม
- **จุดเปลี่ยนชุด:** ในห้องรอมีวงม่วง 👕 (มุมซ้ายหลังห้อง) เดินเข้าไปเพื่อเปิดร้านแต่งตัว กด ✔ เสร็จ แล้วเพื่อนจะเห็นชุดใหม่ทันที (ระหว่างรอบเปลี่ยนไม่ได้)
- **ป้ายเศรษฐี:** ในห้องรอมีป้ายอันดับเหรียญของผู้เล่นที่ออนไลน์ (ข้างขวา) ผู้เล่น Top 3 ได้เหรียญ 🥇🥈🥉 หน้าชื่อ และปลดล็อก **ท่าพิเศษ** 3 ท่า (🏆 ชูถ้วย · 👑 ราชา · 🌟 หมุนสตาร์) ในเมนู 🕺 (กด 8/9/0 บนคอม) — เซิร์ฟเวอร์ตรวจสิทธิ์ทุกครั้ง; หลุด Top 3 ท่าจะถูกล็อก (หมายเหตุ: ยอดเหรียญเก็บในเครื่องผู้เล่นและส่งมาให้เซิร์ฟเวอร์เอง คนดัดแปลงเกมอาจโกงอันดับได้ และอันดับนับเฉพาะคนที่ออนไลน์ตอนนี้)
- **เมนู:** ใส่ชื่อ แต่งตัว (ร้านค้าใช้เหรียญ เริ่มต้นมี 100) แล้วกด "เริ่มเกม"
- **ห้องรอ:** เดิน/แชท/เต้นได้อิสระ กดปุ่ม **▶ เข้าร่วมรอบ** ที่แผงมุมขวา พอมีคนเข้าคิว จะนับถอยหลัง 15 วินาทีแล้วเริ่มรอบ (**เล่นคนเดียวก็ได้**, สูงสุด 12 คนต่อเซิร์ฟเวอร์) คนที่มาทีหลังเข้าคิวรอบถัดไปและดูรอบที่กำลังแข่งได้
- **1 รอบ = 10 มินิเกม** สุ่มจากคลัง **50 มินิเกม** (โจทย์ 25 แบบ × กลไกพิเศษ เช่น แท่นหมุนวน/แท่นเลื่อน/แท่นสลับที่กลางเกม/โจทย์หายไปให้จำ/ชื่อบนแท่นหายไป/กลับด้าน (ยืนบนที่ผิด)/แท่นจิ๋ว/เร็วสุด ๆ) ในรอบเดียวกันโจทย์ไม่ซ้ำตระกูลกัน และเกมพิมพ์ไม่เกิน 2 เกม
- **โจทย์อยู่บนจอมอนิเตอร์ยักษ์ที่ปลายสนาม** (ในฉาก 3D) ไม่บังหน้าจอเหมือนเมื่อก่อน; สนามมีรั้วกระจกรอบขอบ และมีกำแพงพลังงานสีแดงกั้นระหว่างสนามกับห้องรอตอนมีรอบแข่ง — ข้ามออกนอกเขตไม่ได้ (เซิร์ฟเวอร์ล็อกตำแหน่งด้วย)
- **ภาษา (ไทย / EN / ทั้งสอง) สุ่มใหม่ทุกมินิเกม** — ดูป้ายสีม่วงบนจอ; ถ้าเป็นเกมพิมพ์ จะตรวจเฉพาะภาษาที่กำหนด
- **ระบบคะแนน (ไม่มีใครตกรอบ):** ตัวละครวิ่งไปยืนบนแท่นคำตอบก่อนหมดเวลา ถูก = **+10 แต้ม** ใครเข้าแท่นที่ถูกก่อน ได้โบนัสเพิ่ม (ที่ 1 +5, ที่ 2 +3, ที่ 3 +1; เกมพิมพ์นับตามลำดับที่ตอบถูก) ผิด/พลาด = ไม่ได้แต้ม แต่เล่นต่อได้ครบ 10 เกม
- จบแต่ละเกม ทุกคนจะกลับไปเกิดที่จุดเริ่มต้น (เส้นสตาร์ท) ก่อนเริ่มเกมถัดไป
- จบ 10 เกม คนที่แต้มสูงสุดชนะ (เท่ากันชนะร่วมกัน) ได้เหรียญเท่าแต้มที่ทำได้ + 25 ถ้าชนะ
- ปุ่ม 🔊 ปิด/เปิดเสียงเอฟเฟกต์ (และเสียงผู้เล่นอื่น)

### 🎤 แชทเสียง
**กดปุ่ม 🎤 ค้างไว้ (หรือกดค้างคีย์ M) เพื่อพูด ปล่อยเพื่อหยุด** (ครั้งแรกเบราว์เซอร์จะขออนุญาตไมค์ ระบบต่อสายหาทุกคนไว้ล่วงหน้าเลยพูดแล้วได้ยินทันที; สายหลุดจะต่อใหม่อัตโนมัติ) — คนที่พูดอยู่จะมีไอคอน 🔊 ที่ชื่อ; ในห้องรอเสียงเบาลงตามระยะห่าง ข้อควรรู้:
- ไมค์ใช้ได้เฉพาะหน้าเว็บ **https** (เช่น GitHub Pages) หรือ **localhost** เท่านั้น — `start.sh` จึงเปิดหน้าเกมเป็น **https** (ใบรับรองจำลอง: ครั้งแรกเบราว์เซอร์จะเตือน "ไม่ปลอดภัย" ให้กด ขั้นสูง → ดำเนินการต่อ) และส่งต่อ WebSocket ผ่านช่อง `/ws` เดียวกัน; มือถือให้เปิดลิงก์ `https://<IP เครื่อง>:5173` ที่ Vite แสดง (ถ้าไม่ต้องการ https: `NO_HTTPS=1`); ผู้ฟังไม่ต้องมีไมค์
- ใช้ WebRTC ต่อตรงระหว่างผู้เล่น (เซิร์ฟเวอร์ส่งต่อแค่สัญญาณเชื่อมต่อ) ใช้ STUN ของ Google บางเครือข่าย (เช่น เน็ตมือถือบางเจ้า/ไฟร์วอลล์โรงเรียน) อาจเชื่อมไม่ติดถ้าไม่มี TURN — ตั้ง `VITE_ICE_SERVERS` (JSON เช่น `[{"urls":"turn:...","username":"..","credential":".."}]`) ตอน build เพื่อเพิ่ม TURN
- คนที่พูดจะส่งเสียงไปหาผู้ฟังไม่เกิน 20 คนพร้อมกัน

โจทย์ยากขึ้นตามลำดับเกมในรอบ (สายตรง → มีหมู่แทนที่ → พันธะคู่/สาม → แทนที่หลายตำแหน่ง)

## รันในเครื่อง
ต้องมี Node.js 20+

```bash
# เทอร์มินัล 1: เซิร์ฟเวอร์ (พอร์ต 8080)
cd server && npm install && npm start

# เทอร์มินัล 2: หน้าเกม
cd client && npm install && npm run dev      # เปิด http://localhost:5173
```
เปิดหลายหน้าต่างเพื่อลองเล่นหลายคน: หน้าต่างแรกกด ＋ สร้างห้อง อีกหน้าต่างเลือกห้องนั้น (หน้าเกมเชื่อมเซิร์ฟเวอร์ที่พอร์ต 8080 ของเครื่องเดียวกันอัตโนมัติ)

ลองเซิร์ฟเวอร์แบบ Cloudflare ในเครื่อง: `npx wrangler dev` (พอร์ต 8787) แล้วรันหน้าเกมด้วย `VITE_API_URL=http://localhost:8787 npm run dev`

**เล่นกับเพื่อนในเน็ตเดียวกัน (Wi-Fi/LAN):** รันหน้าเกมด้วย `npm run dev -- --host` แล้วให้เพื่อนเปิดลิงก์ `http://<IP เครื่องคุณ>:5173` (บน Mac ดู IP ด้วย `ipconfig getifaddr en0`) ถ้า macOS ถามเรื่อง firewall ให้กด Allow

ทดสอบอัตโนมัติ: `cd server && npm test` (ตรวจการตั้งชื่อ IUPAC กับตัวอย่างที่รู้เฉลย + จำลองผู้เล่น 3 คนเล่นจนจบ)

## ระบบหลายห้อง (ผู้เล่นสร้างห้องเอง)
กด "▶ เริ่มเกม" แล้วจะเจอหน้า **เลือกห้อง**: เห็นห้องที่ออนไลน์ (ชื่อ, 🔒 ล็อกรหัส, จำนวนคน, กำลังแข่งหรือรอเริ่ม), กด **＋ สร้างห้อง** ตั้งชื่อ + รหัสผ่าน (ไม่ใส่ = ห้องเปิด) ผู้สร้างเป็น **เจ้าของห้อง 👑** กดที่ 👥 มุมซ้ายบนเพื่อดูรายชื่อและเตะผู้เล่นได้ ถ้าเจ้าของออก สิทธิ์ส่งต่อให้คนถัดไป ห้องที่ไม่มีคนจะหายเอง เล่นข้ามเครือข่ายได้เพราะทุกคนต่อเข้าเซิร์ฟเวอร์กลางตัวเดียวกัน

โค้ดแยกเป็น 3 ส่วน: `server/room.js` (ลอจิกเกม 1 ห้อง ไม่ผูกกับระบบใด) · `server/server.js` (ตัวเชื่อม Node: รันในเครื่อง/Render) · `server/worker.js` (ตัวเชื่อม Cloudflare Workers + Durable Objects)

## Deploy (แนะนำ: Cloudflare Workers + GitHub Pages — ไม่มีใครต้องดูแล)

### 1) เซิร์ฟเวอร์บน Cloudflare (ฟรี ไม่หลับ ไม่ต้องใส่บัตร)
ทำครั้งเดียวในเครื่องที่มี Node.js 20+:
```bash
npm install                       # ที่โฟลเดอร์โปรเจกต์ (ติดตั้ง wrangler)
npx wrangler login                # เปิดเบราว์เซอร์ให้ล็อกอิน/สมัคร Cloudflare ฟรี
npx wrangler deploy               # ได้ URL เช่น https://chem-arena.ชื่อคุณ.workers.dev
```
จดลิงก์ `https://chem-arena.ชื่อคุณ.workers.dev` ไว้ (ทดสอบ: เปิด `…/api/rooms` ต้องเห็น `{"rooms":[]}`)

**โควตาแผนฟรีของ Cloudflare (ตรวจเงื่อนไขล่าสุดก่อนใช้งานจริง):** Durable Objects ฟรีได้ 100,000 requests/วัน และข้อความ WebSocket ขาเข้านับ 20 ข้อความ = 1 request เกมนี้ส่งตำแหน่งสูงสุด ~5 ครั้ง/วินาที/คนตอนเดิน ห้อง 12 คนเดินตลอดเวลาจะกินโควตาประมาณ 3 ชม./วัน ใช้ในห้องเรียน/ส่งครูพอเพียงมาก ถ้าเกินโควตา ระบบจะใช้ไม่ได้จนรีเซ็ต 00:00 UTC (7 โมงเช้าไทย) ไม่มีค่าใช้จ่ายเพิ่มเอง

### 2) หน้าเกมบน GitHub Pages
1. push โปรเจกต์ขึ้น GitHub
2. Repo → **Settings → Secrets and variables → Actions → Variables** เพิ่มตัวแปร `VITE_API_URL` = `https://chem-arena.ชื่อคุณ.workers.dev` (ลิงก์จากข้อ 1 ไม่มี `/` ท้าย)
3. **Settings → Pages → Source: GitHub Actions**
4. push ขึ้น `main` workflow จะ build และ deploy ให้ เกมอยู่ที่ `https://USERNAME.github.io/REPO/`

### เซิร์ฟเวอร์สำรอง (Node บน Render) — ให้ผู้เล่นเลือกได้ 2 ระบบ
หน้าเลือกห้องจะมีปุ่มสลับ **☁️ Cloudflare / 🖥 เซิร์ฟเวอร์สำรอง** (โค้ดเซิร์ฟเวอร์ตัวเดียวกัน แต่ห้องของแต่ละระบบแยกกัน) ถ้าโควตา Cloudflare วันนี้เต็ม จะขึ้นข้อความ "โควตาเต็ม กลับมาใช้ได้ 07:00 น. เวลาไทยของวันพรุ่งนี้" พร้อมแนะนำให้สลับไปเซิร์ฟเวอร์สำรอง
Render → New → **Blueprint** → เลือก repo นี้ (`render.yaml`) ได้ URL เช่น `https://chem-arena-server.onrender.com` แล้วเพิ่ม GitHub Variable `VITE_API_URL2` = URL นั้น (แผนฟรีของ Render หลับเมื่อไม่มีคนใช้ ต้องรอปลุก ~1 นาที) ถ้าตั้งแค่ตัวเดียว ปุ่มสลับจะไม่แสดง

## สกิล ⚡ (ซื้อด้วยเหรียญ อัปเลเวลได้)
ซื้อ/อัปที่ร้านแต่งตัว แท็บ **⚡ สกิล** (เมนูตอนเริ่ม หรือจุดวงม่วงในห้องรอ) ใช้ได้เฉพาะตอนกำลังแข่ง ปุ่มสกิลอยู่มุมขวาล่าง (หรือกดคีย์ลัด Z X C V B N H) เซิร์ฟเวอร์ตรวจสิทธิ์/จำนวนครั้ง/คูลดาวน์เอง

| สกิล | ทำอะไร | Lv1 / Lv2 / Lv3 (ครั้งต่อรอบ) | ราคา ซื้อ / อัป |
|---|---|---|---|
| 👁 ส่องตา | เห็นผู้เล่นคนอื่นชั่วคราว (ปกติถูกซ่อนตอนเล่น) | 1 / 2 / 3 · 4-5-6 วิ | 120 / 200 / 320 |
| ⚡ พุ่ง | วิ่งเร็วขึ้น 50% | 1 / 2 / 3 · 5-6-8 วิ | 100 / 160 / 260 |
| 🛡 โล่ | กันสกิลแกล้งที่โดนครั้งต่อไป | 1 / 1 / 2 | 150 / 240 / 360 |
| 💡 ใบ้ | ขีดฆ่าแท่นที่ผิด 1 แท่น (ไม่ใช้กับเกมพิมพ์) | 1 / 1 / 2 | 300 / 450 / 650 |
| 🧊 แช่แข็ง | เป้าหมายขยับไม่ได้ | 1 / 1 / 2 · 2-3-4 วิ | 200 / 320 / 480 |
| 🙃 กลับทิศ | ปุ่มเดินของเป้าหมายกลับด้าน | 1 / 2 / 2 · 3-4-5 วิ | 160 / 260 / 400 |
| 💨 ลมพัด | ผลักเป้าหมายไปทางสุ่ม | 1 / 1 / 2 | 220 / 340 / 520 |

กติกากันโกง/กันแกล้งเกินไป: สกิลแกล้ง (🧊🙃💨) ใช้ไม่ได้ใน 3 วินาทีสุดท้ายของแต่ละเกม · เป้าหมายที่เพิ่งโดนจะมีภูมิคุ้มกัน 5 วินาที · เว้นคูลดาวน์ 2.5 วินาทีระหว่างสกิล · ทุกคนในห้องเห็นข้อความว่าใครแกล้งใคร แก้ตัวเลขได้ที่ `server/skills.js` และ `client/src/skills.js` (ต้องตรงกัน) ระดับสกิลเก็บในเบราว์เซอร์เหมือนเหรียญ ผู้เล่นที่ดัดแปลงเกมอาจให้ตัวเองมีสกิลฟรีได้

## ข้อจำกัดที่ควรรู้
- ชื่อไทยของสาร (เช่น เอทิล/อีเทน, ไซ/ซี) แต่ละตำราสะกดไม่เหมือนกัน ตารางใน `names.js` รองรับหลายแบบแล้ว แต่ควรเทียบกับตำราของครู ถ้าไม่ตรงให้เพิ่มคำสะกดในตาราง
- เหรียญและของที่ซื้อเก็บในเบราว์เซอร์ผู้เล่น (localStorage) ผู้เล่นที่รู้เรื่องเทคนิคแก้ได้ ถ้าต้องการระบบจริงจังต้องเพิ่มบัญชีผู้ใช้และฐานข้อมูลฝั่งเซิร์ฟเวอร์
- เซิร์ฟเวอร์ตรวจคำตอบและถือเฉลยเอง ผู้เล่นดูเฉลยจากโค้ดหน้าเกมไม่ได้
- มือถือแนวนอนจอเล็ก ตัวหนังสือบนจอมอนิเตอร์จะเล็ก ใช้ถ่างสองนิ้วซูมเข้าไปได้ (กติกาสั้น ๆ แสดงที่แถบล่างด้วย); ตอนเปิดแป้นพิมพ์พื้นที่เหลือน้อย แนะนำให้เล่นแนวตั้งเวลาต้องพิมพ์คำตอบ
- ห้องบน Cloudflare: รายชื่อห้องกลางเก็บในหน่วยความจำ (รีเซ็ตได้เมื่อระบบย้ายเครื่อง จะกลับมาเองภายใน ~30 วินาทีเมื่อห้องรายงานตัว) รหัสผ่านห้องเก็บเป็นค่าแฮช SHA-256 ไม่เก็บตัวจริง แต่เป็นระบบกันคนทั่วไป ไม่ใช่ความปลอดภัยระดับธนาคาร
- ตำแหน่งผู้เล่นมาจากไคลเอนต์ เซิร์ฟเวอร์ล็อกแค่ขอบเขต ยังไม่ได้ตรวจความเร็ว (คนโกงที่ดัดแปลงเกมอาจวาร์ปไปแท่นได้)
- ทดสอบมือถือด้วยหน้าจอจำลองใน Chrome เท่านั้น ยังไม่ได้ลองกับเครื่องจริง (iPhone/Android) และการพิมพ์ไทยด้วยแป้นพิมพ์จริง

## ตัวละคร (Roblox R15)

ตัวละครใช้โมเดล R15 ที่ผู้ใช้ส่งมา (`client/src/character-data.json` แปลงจากไฟล์ .obj แล้ว) แบ่งเป็น 15 ชิ้นส่วนเชื่อมด้วยข้อต่อ (ไม่ใช่ skinning) และขยับด้วยแอนิเมชันโค้ด: เดิน / ยืนนิ่ง / กระโดด / นั่ง (`client/src/avatar.js`)
- โมเดลไม่มีไฟล์ .mtl และไม่มีtexture หน้า สีตัวมาจากร้านค้า ส่วนตาเป็นลูกกลม
- หมวกและแว่นยังใช้ได้ตามเดิม

## ร้านแต่งตัว (v2)

หน้าร้านเป็นการ์ดแบบ Roblox มีแท็บ: ทั้งหมด · สีตัว · ผม · สีผม · หมวก · หน้า · หน้ากาก/แว่น · เสื้อ · กางเกง
- ข้อมูลไอเทมและราคาอยู่ใน `client/src/shop.js` (เพิ่มไอเทมใหม่ = เพิ่มบรรทัดในรายการ แล้วเพิ่มโค้ดวาดใน `setOutfit` ของ `client/src/avatar.js`)
- ผม/หมวก/หน้า/แว่น/ลายเสื้อ ประกอบจากทรงพื้นฐาน (กล่อง/ทรงกลม/กรวย) ติดบนข้อต่อของตัวละคร เลยขยับตามตอนเดินและนั่ง
- เซิร์ฟเวอร์ตรวจรูปแบบของชุดแต่งตัวเท่านั้น (เป็นแค่ภาพ) ถ้าเพิ่มหมวดใหม่ ให้เพิ่มชื่อฟิลด์ใน `OUTFIT_DEF` ของ `server/server.js`
- เซฟเก่าที่ใช้ฟิลด์ `glasses` จะถูกแปลงเป็น `mask` อัตโนมัติ

## Log ใน terminal (server)

server แสดง log สีพร้อมเวลา (เวลาไทย): คนเข้า/ออก (ชื่อ ไอพี เวลาที่อยู่ จำนวนออนไลน์), จบรอบ (ผู้ชนะ) — ปิดสีด้วย `NO_COLOR=1 node server.js`

## แชท + ท่าเต้น

- **แชท**: กด `Enter` (หรือปุ่ม 💬 บนจอ) พิมพ์ข้อความแล้วกดส่ง ทุกคนในล็อบบี้เห็น และมีกล่องคำพูดลอยเหนือหัวตัวละคร 5 วินาที จำกัด 80 ตัวอักษร ส่งได้ 1 ข้อความต่อ 0.7 วินาที (กันสแปม) เซิร์ฟเวอร์ตัดอักขระควบคุมและ `<>` ออก แชทใช้ได้ทั้งในห้องรอและระหว่างรอบแข่ง
- **ท่าเต้น**: กด `1`–`7` หรือปุ่ม 🕺 บนจอ: โบกมือ · โค้งคำนับ · ดิสโก้ · หุ่นยนต์ · ฮึบ! · ส่ายสะโพก · ฟลอส เดินหรือกระโดด = เลิกเต้น คนอื่นเห็นท่าเต้นของคุณ (คนที่เข้ามาทีหลังก็เห็น)
- ท่าเต้นเป็นสูตรคำนวณใน `emotePose()` ของ `client/src/avatar.js` เพิ่มท่าใหม่ = เพิ่มในรายการ `EMOTES` + เพิ่มเงื่อนไขใน `emotePose` + เพิ่มชื่อใน `EMOTES` ของ `server/server.js`

- ตำแหน่งผู้เล่นที่ตัดสินแท่นมาจากเครื่องผู้เล่น (เซิร์ฟเวอร์จำกัดแค่ขอบสนาม) ผู้ที่ดัดแปลงโค้ดฝั่งเว็บอาจวาร์ปไปยืนแท่นถูกได้ ถ้าจะจริงจังต้องเพิ่มการตรวจความเร็วการเดินฝั่งเซิร์ฟเวอร์
